# TCMS Adapter（中文说明）

**`tcms-*` 系列的一员** —— 面向科技产品营销团队的品牌方内容 Skill。
*不是中立第三方产业研究，那是 `industry-deep-dive-pipeline` 的职责。*

## 功能

将已审核核心稿适配为各渠道版本（公众号、开发者社区、中文社交、英文X、LinkedIn、销售一页纸），并对已发布内容做二次推广物料生成。

不从零创作——那是 `tcms-writer` 的职责。各渠道版本保持品牌命名、数据点、客户脱敏一致。

## 触发词

适配, 改写, 多渠道版本, 渠道版本, 公众号版, 社交帖, 英文帖, 二次推广, adapt, repurpose

## 流水线位置

`tcms-planner`（选题）→ `tcms-writer`（初稿）→ `tcms-compliance-reviewer`（预审）→ `tcms-adapter`（渠道）→ `tcms-performance-analyst`（月度报告）
