# TCMS Adapter

**Part of the `tcms-*` family** — brand-side content skills for tech-product marketing teams.
*Not for neutral third-party industry research — that is `industry-deep-dive-pipeline`'s job.*

## What it does

Adapts a reviewed core draft into channel-specific versions (WeChat, dev community, CN social, EN X, LinkedIn, sales one-pager) and repurposes published content.

It never writes from scratch — that is `tcms-writer`'s job. Keeps brand naming, data points, and customer redaction consistent across channels.

## Trigger phrases

适配, 改写, 多渠道版本, 渠道版本, 公众号版, 社交帖, 英文帖, 二次推广, adapt, repurpose

## Pipeline position

`tcms-planner` (brief) → `tcms-writer` (draft) → `tcms-compliance-reviewer` (review) → `tcms-adapter` (channels) → `tcms-performance-analyst` (monthly report)
